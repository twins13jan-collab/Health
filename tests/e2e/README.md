# اختبارات التكامل الحية (E2E)

مجموعة اختبارات طرف-لطرف داخل المستودع — كانت اختبارات الدخان
تعيش في ملفات مؤقتة وتضيع مع كل استبدال للبيئة؛ هذه النسخ
محفوظة وتعمل ضد المنظومة الحية:

- `test_journey_e2e.py` — رحلة مريض كاملة عبر وحدات حقيقية
  (مرضى ← لقاء ← معمل ← صيدلة ← فوترة ← خروج) بمعرف ارتباط واحد.
- `test_notifications.py` — صندوق الإشعارات: إرسال فعلي، وفشل
  أمين عند غياب بوابة، وحد محاولات.
- `test_rbac_matrix.py` — مصفوفة الصلاحيات على الكتابة.
- `test_reference_data.py` — البيانات المرجعية الوطنية.
- `test_analytics_proxy.py` — ربط التحليلات عبر المنصة.
- `test_print_documents.py` — مستندات PDF الرسمية من سجلات حقيقية.
- `test_pagination.py` — ترقيم صفحات القوائم الأساسية.

التشغيل: `./run_all.sh` (المتغير `EHS_BASE` يغيّر العنوان).
